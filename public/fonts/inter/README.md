# Inter v4.1

Unmodified variable upright WOFF2 from the official Inter distribution:
https://rsms.me/inter/font-files/InterVariable.woff2?v=4.1

Project: https://rsms.me/inter/ and https://github.com/rsms/inter

Copyright and SIL Open Font License terms are retained in LICENSE.txt (from
https://raw.githubusercontent.com/rsms/inter/v4.1/LICENSE.txt).

The font is self-hosted and used only in staff workspaces, staff sign-in and
support chat. It loads when those surfaces need it; there is no external font
request or page-wide preload. The approved public storefront typefaces remain.
